# Компонент налаштувань Chartex

Цей компонент надає користувачам можливість налаштовувати різні аспекти роботи додатку Chartex.

## Функціональність

### 1. Налаштування збору даних
- **Увімкнути збір даних** - головний перемикач для активації/деактивації збору даних
- **Збирати історію відвідувань** - зберігати URL та час відвідування сайтів
- **Збирати інформацію про пристрій** - зберігати тип пристрою, браузер та ОС
- **Збирати заголовки сторінок** - зберігати назви сторінок для кращого відображення
- **Збирати тривалість відвідувань** - вимірювати час, проведений на кожному сайті

### 2. Налаштування приватності
- **Шифрувати дані** - захищати дані за допомогою шифрування
- **Надсилати анонімну статистику** - допомогти покращити extension (без особистих даних)
- **Показувати інформацію про пристрої** - відображати детальну інформацію про пристрої в статистиці

### 3. Налаштування відображення
- **Мова інтерфейсу** - вибір мови (Українська, English, Русский)
- **Тема** - вибір теми (Світла, Темна, Автоматично)
- **Формат часу** - 24-годинний або 12-годинний формат
- **Формат дати** - різні формати дати (ДД.ММ.РРРР, ММ/ДД/РРРР, РРРР-ММ-ДД)

## Архітектура

### Компоненти
- `SettingsComponent` - основний компонент налаштувань
- `SettingsService` - сервіс для управління налаштуваннями

### Збереження даних
- Налаштування зберігаються в `localStorage`
- Автоматична синхронізація з Chrome extension
- Reactive підхід з використанням RxJS

### Навігація
- Кнопка "Назад" для повернення до дашборду
- Меню користувача з можливістю виходу
- Захист маршруту через `authGuard`

## Використання

### В dashboard компоненті
```typescript
// Перехід до налаштувань
openSettings() {
  this.router.navigate(['/settings']);
}

// Вихід з системи
logout() {
  this.authService.logout().subscribe(() => {
    // Обробка виходу
  });
}
```

### В HTML
```html
<button mat-menu-item (click)="openSettings()">
  <mat-icon>settings</mat-icon>
  <span>Налаштування</span>
</button>
<button mat-menu-item (click)="logout()">
  <mat-icon>logout</mat-icon>
  <span>Вийти</span>
</button>
```

## Маршрутизація

Додано новий маршрут в `app.routes.ts`:
```typescript
{ 
  path: 'settings', 
  component: SettingsComponent,
  canActivate: [authGuard]
}
```

## Стилізація

- Responsive дизайн для різних розмірів екрану
- Анімації та переходи для кращого UX

## Інтеграція з Extension

Налаштування автоматично відправляються до Chrome extension через `chrome.runtime.sendMessage`:
```typescript
chrome.runtime.sendMessage({
  action: 'updateSettings',
  settings: {
    dataCollection: {...},
    privacy: {...},
    display: {...}
  }
});
```
