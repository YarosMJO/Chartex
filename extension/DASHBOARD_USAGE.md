# 📊 Використання Chartex Analytics Dashboard

## Як відкрити Dashboard

### Спосіб 1: Через Popup
1. Клікніть на іконку Chartex extension в панелі інструментів
2. У popup вікні натисніть кнопку **"📊 Відкрити аналітику"**
3. Dashboard відкриється в новій вкладці

### Спосіб 2: Через Chrome Settings
1. Відкрийте `chrome://extensions/`
2. Знайдіть Chartex extension
3. Клікніть **"Details"**
4. Натисніть **"Extension options"**

## Налаштування збору даних

### ✅ Включити збір
1. У popup натисніть **"▶️ Почати збір даних"**
2. Або через контекстне меню: **"Перемкнути збір даних"**

### ⏹️ Зупинити збір
1. У popup натисніть **"⏹️ Зупинити збір"**
2. Або через контекстне меню: **"Перемкнути збір даних"**

## Тестування

### 🧪 Тест даних
1. У popup натисніть **"🧪 Тест даних"**
2. Перевірте консоль для результатів
3. Перевірте, чи дані з'явилися в dashboard

## Поширені питання

### Q: Dashboard не відкривається
**A:** Перевірте:
- Чи правильно налаштований `options_page` в manifest.json
- Чи існує файл `dashboard/dashboard.html`
- Чи немає помилок в консолі

### Q: Дані не з'являються в dashboard
**A:** Перевірте:
- Чи запущений збір даних
- Чи працює backend API
- Чи правильно налаштована авторизація

### Q: Dashboard повільний
**A:** Спробуйте:
- Зменшити період фільтрації
- Очистити кеш браузера
- Перезавантажити extension

## Структура файлів

```
extension/
├── dashboard/
│   ├── dashboard.html      # Головна сторінка dashboard
│   ├── main-*.js          # Angular додаток
│   ├── styles-*.css       # Стилі
│   └── indigo-pink.css    # Material Design тема
├── popup.html             # Popup з кнопкою відкриття
├── popup.js               # Логіка popup
├── background.js          # Service Worker
└── manifest.json          # Налаштування extension
```

## Розробка

### Локальна розробка
1. Запустіть Angular dev server: `ng serve`
2. Відкрийте `http://localhost:4200`
3. Тестуйте зміни

### Збірка для production
1. Виконайте: `ng build --prod`
2. Скопіюйте файли в `extension/dashboard/`
3. Перезавантажте extension

### Оновлення dashboard
1. Внесіть зміни в Angular код
2. Збудуйте проект
3. Оновіть файли в extension
4. Перезавантажте extension
