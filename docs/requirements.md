# Проект Chartex — Веб-аналітика та візуалізація історії браузерної активності

## Основна ідея
Браузерне розширення, що відкриває SPA для аналітики та візуалізації історії браузерної активності користувача.

---

## Технології
- **Frontend:** Angular, Angular Material, ApexCharts
- **Backend:** Node.js + Express
- **База даних:** MongoDB
- **Аутентифікація:** Firebase Auth
- **Доступ до історії:** Chrome API (chrome.history)
- **SPA відкривається через розширення Chrome**

---

## Основні функції
- Візуалізація історії браузера (графіки через ApexCharts)
- Фільтр по даті
- Пошук по історії
- Аутентифікація користувача (Firebase Auth)
- Синхронізація історії між пристроями (з ідентифікатором пристрою)
- Перегляд історії з усіх пристроїв разом або окремо
- Зберігання лише найнеобхіднішого для аналітики на сервері

---

## Розширений збір даних (якщо не мінімальний)
- faviconUrl, duration, referrer, visitCount, typedCount, transitionType, userAgent, geoLocation, tags, screenResolution, language, sessionId, notes

---

## Приватність та GDPR
- **Zero Knowledge:** Вся приватна інформація шифрується на клієнті (AES), ключ лише у користувача
- Сервер зберігає лише зашифровані дані
- Користувач може видалити свої дані
- Глобальна аналітика: зберігаються лише анонімізовані/агреговані дані (хеші доменів, кількість відвідувань, часові патерни, типи пристроїв)

---

## Структура проекту
- **backend/** — Node.js + Express API
- **frontend/** — Angular SPA
- **extension/** — Chrome Extension (popup, маніфест, скрипти)
- **docs/** — документація, вимоги, інструкції
