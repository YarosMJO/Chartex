# 🤝 Внесок в Chartex

Дякуємо за інтерес до проекту Chartex! Ми вітаємо внесок від спільноти.

## 📋 Як внести свій внесок

### 🐛 Повідомлення про помилки

1. Перевірте, чи проблема вже не повідомлена в [Issues](https://github.com/your-username/chartex/issues)
2. Створіть нове issue з описом проблеми
3. Включіть:
   - Опис проблеми
   - Кроки для відтворення
   - Очікувана поведінка
   - Фактична поведінка
   - Скріншоти (якщо потрібно)
   - Версія браузера/ОС

### 💡 Запити функцій

1. Перевірте, чи функція вже не запропонована
2. Створіть issue з тегом `enhancement`
3. Опишіть:
   - Яку проблему вирішує функція
   - Як вона повинна працювати
   - Приклади використання

### 🔧 Розробка

#### Налаштування середовища розробки

1. **Fork репозиторію**
```bash
git clone https://github.com/your-username/chartex.git
cd chartex
```

2. **Встановіть залежності**
```bash
# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install

# Extension (опціонально)
cd ../extension
# Перевірте, чи всі файли на місці
```

3. **Налаштуйте змінні середовища**
```bash
# Backend
cd backend
cp .env.example .env
# Відредагуйте .env файл
```

#### Структура коду

- **Backend**: Node.js + Express + MongoDB
- **Frontend**: Angular 17 + Material Design
- **Extension**: Chrome Extension Manifest V3

#### Стандарти коду

- **JavaScript/TypeScript**: ESLint + Prettier
- **Коментарі**: Українською мовою
- **Commit повідомлення**: Англійською мовою
- **Функції**: JSDoc коментарі

#### Тестування

```bash
# Backend тести
cd backend
npm test

# Frontend тести
cd frontend
ng test
ng e2e

# Extension тести
# Відкрийте chrome-extension://[ID]/test-config.html
```

### 📝 Pull Request процес

1. **Створіть feature branch**
```bash
git checkout -b feature/amazing-feature
```

2. **Зробіть зміни**
- Дотримуйтесь стандартів коду
- Додайте тести для нової функціональності
- Оновіть документацію

3. **Commit зміни**
```bash
git add .
git commit -m "feat: add amazing feature"
```

4. **Push до вашого fork**
```bash
git push origin feature/amazing-feature
```

5. **Створіть Pull Request**
- Заповніть шаблон PR
- Опишіть зміни
- Додайте скріншоти (якщо потрібно)
